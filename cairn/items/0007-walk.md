## Ships

An agent writes a horsegirl file, checks it, applies the fixes, and draws a flow diagram as SVG, from the command line or over MCP.

## Acceptance criteria

- [ ] `horsegirl check`, `fix`, `fmt`, `draw` and `spec` work on Linux and macOS from a release binary.
- [ ] 100 real flowcharts from public repositories draw with no overlap.
- [ ] A model that has only the spec card writes a valid file on the first try in 95 of 100 benchmark tasks.
- [ ] The website has a landing page, an install page and the language reference.

## Explicitly not in this milestone

- Stories, and every lens except flow.
- The read-back (`describe`), Mermaid import, themes other than plain.
- Layout that stays stable across edits.
- A playground in the browser.
