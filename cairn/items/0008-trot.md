## Ships

Stories draw as sequences and lanes, the agent reads any picture back as text, Mermaid goes in and out, and the playground runs in a browser.

## Acceptance criteria

- [ ] One file draws as flow, sequence and lanes with no change to its facts.
- [ ] An agent finds a wrong diagram from the read-back alone in 9 of 10 seeded cases.
- [ ] A repository replaces its Mermaid renderer by changing one line of CI.
- [ ] The playground on the website runs the WebAssembly build.

## Explicitly not in this milestone

- Stable layout, evidence and `verify`, picture diffs.
- Matrix, rings, seams, storyline, and lenses that need data files.
