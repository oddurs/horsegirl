## Ships

A layout keeps its shape when the source changes, facts cite their evidence, a pull request shows a picture of what changed, and four more lenses exist.

## Acceptance criteria

- [ ] Adding one node to a 50-node diagram moves fewer than three other nodes.
- [ ] `verify` reports a fact whose cited file no longer supports it.
- [ ] The GitHub Action comments a picture diff on a pull request.
- [ ] Matrix, rings, seams and storyline draw the reference examples.
