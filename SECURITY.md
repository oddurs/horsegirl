# Security

## Supported versions

There is no release yet. After the first release, the latest release receives
security fixes.

## Report a vulnerability

Report privately through
[GitHub Security Advisories](https://github.com/oddurs/horsegirl/security/advisories/new).
Do not open a public issue.

Expect a first reply within seven days. A confirmed vulnerability gets a fix or
a mitigation plan within thirty days, and credit in the advisory if you want it.

## Scope

horsegirl reads files that other people wrote. A file that makes the parser
panic, hang, or read outside the paths it was given is a vulnerability.
